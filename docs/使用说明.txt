目录模板 1.0 · 使用说明
========================================

一、安装
1. 把左边的「目录模板」拖到右边的「应用程序」文件夹。
2. 首次打开：在「应用程序」里右键 App →「打开」。
   App 为本地签名（ad-hoc），没有做 Apple 公证，首次打开确认一次即可。
3. 如果系统提示“已损坏，无法打开”，打开「终端」执行：
   xattr -dr com.apple.quarantine /Applications/目录模板.app

二、快速建模板（重点）
模板编辑区是一张横向思维导图：根节点在最左边，分支向右展开。
画布是一个独立的焦点区域：先点一下画布或任意节点，画布四周会出现蓝色边框，
表示已激活，这时 Tab 才作用于导图；点侧栏、右侧面板或模板名称输入框后，
边框消失，Tab 恢复成系统默认的切换焦点。

键盘就能连续录入，不用来回点按钮：

1. 点「添加根目录」，直接输入文件夹名称。
2. 按 回车：保存这个名字，并立刻在下面创建下一个同级文件夹。
   继续输入、继续回车，就能一节一节把同级目录建完。
3. 按 Tab：保存当前名字，并在这个文件夹下面创建子级，光标直接落在子级里。
   子级里再按 回车 建同级、再按 Tab 继续往下钻。
   画布上会实时长出新的节点和彩色连线。
4. 按 Esc，或点画布空白处 / 其他区域：结束当前命名。
   如果名字还是空的，这个空文件夹会被自动移除，不会卡在待命名状态；
   新建时顶部提示条右侧也有「取消命名」按钮。
5. 单击文件夹立即选中；在已选中的文件夹上再点一次，直接进入改名。
   重命名时按 回车 只保存，不会再多建一个。

示例：做「01 素材 / 视频、音频」结构
  添加根目录 → 输入「01 素材」→ Tab → 输入「视频」→ 回车
  → 输入「音频」→ 回车 → Esc
  结果：01 素材 下面有「视频」「音频」两个同级文件夹。

三、生成项目
1. 右侧填写项目名称（根文件夹名 = 项目名称，每个项目可以不同）。
2. 选择目标位置，点「生成项目」（或按 ⌘G）。
3. 生成后点「显示」在 Finder 中查看；左下「最近创建」里可以右键重命名文件夹，
   会同步重命名磁盘上的真实目录。

四、项目名称与复制粘贴
- 输入框支持 ⌘C / ⌘V / ⌘A 和右键菜单，右侧还有「粘贴剪贴板」按钮。
  Gate 的 Electron 菜单缺少「编辑」菜单，所以项目名里粘贴失效；
  这个版本使用原生输入框并补齐了完整编辑菜单，可以直接粘贴。

五、文件夹名称里的变量
{项目名}     当前项目名称
{日期}       2025-03-07
{yyyyMMdd}   20250307
{时间}       14-30
{年} {月} {日}

例如「{日期} 交付」会在生成时变成「2025-03-07 交付」。

六、快捷键
回车      新建同级 / 保存后继续建同级
Tab       基于当前文件夹新建子级（需先激活画布）
Esc       取消输入
⌘N        新建模板
⌘O        导入模板
⌘E        导出当前模板
⌘G        生成项目
⌘R        重命名选中文件夹
⌫         删除选中文件夹
⌘C / ⌘V / ⌘A   复制 / 粘贴 / 全选

七、数据位置
~/Library/Application Support/DirTemplate/library.json

模板只保存在本机，不联网、不上传。
卸载 App 不会删除模板库；要彻底清除，手动删除上面的文件夹即可。

八、常见问题
- 能分享模板吗？
  可以。右键模板「导出模板…」得到 JSON，对方用「导入模板…」导入。
- 删除模板会删掉已生成的项目文件夹吗？
  不会，只删除模板本身。
- 生成时提示同名文件夹？
  可以选「使用 项目 2」自动编号，也可以返回修改项目名称。
- 支持 Windows 吗？
  不支持，这是 macOS 原生版本，需要 macOS 14 及以上，Intel 与 Apple 芯片都可以运行。
- 模板里有重名文件夹怎么办？
  生成前会给出橙色提示，改成不同名称即可。
